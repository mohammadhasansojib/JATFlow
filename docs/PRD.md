# Product Requirement Document
JATFlow is a Job Application Tracking system which let us add/edit/delete our job application and tracking resume versioning also.

## MVP Features

- authentication
- add/edit/delete job application
- resume versioning
- application status update
- statistics dashboard

## Features to add later
- Sync with google calender
- Connect with a google sheet from where can fetch applications data
- JD analysis
- get upcoming dates/event in notification and email
- Resume Version Tracking
- Kanban view (Applied -> screening -> Interview -> offer -> Rejected)
- mock interview according to job description
- specific job application status based on mock interview result
- Sync with Google Canelder
- JD link/text paste to extract information
